# 太阳能充电监测 · OLED 中文版

解压后双击 Keil/SolarDetector_OLED.uvprojx。目标芯片为 STM32G031F8P6，使用 Arm Compiler 6 和 Keil STM32G0xx_DFP 支持包。源码、头文件、启动文件和链接配置均随包提供。

演示分支请在 Keil 重新构建。原 ZIP 里的 solar_detector_oled.hex 是基线固件。在 Keil 中可选择 ST-Link Debugger、SWD，使用 Flash → Download。现有工程的 U9 接线依次为 GND、3.3V、SCL 和 SDA。OLED 为 128×64 I²C 屏，使用 0x3C 地址。若旧版 Keil 在其他电脑上遇到目录编码问题，可把解压后的工程文件夹改成英文名。

OLED布局预览.png 使用示例数据。实物上方固定为「太阳能充电检测装置」。左列显示板端输入电压、电流、功率，单位为 V、mA、W。右列显示环境温度、相对湿度和充电开关状态。

- 「充电 关闭」表示本固件未开启充电支路。
- 「充电 请求」表示程序发出开启请求，硬件的实际充电状态需另行测量。
- 电流数字每轮刷新，右侧「!」表示已确认超过 630 mA。第一笔可用读数建立初始状态，之后连续 3 笔可用读数落在另一侧才切换标记。回到原状态或出现不可用读数会清除确认计数。
- 原始 ADC 值达到 4000 时，电流格立即显示「超限」。ADC 采样失败时显示「无效」。功率和充电控制继续使用本轮的即时判断。

烧录前按板子接线确认 H1 的 GND、SWDIO 和 SWCLK。H1 第 4 针为 VIN。首次联调先用板上 USB-C 供电，电池暂不接入。

本版默认关闭蜂鸣器，OLED 保留异常提示。已完成编译及版式预览。实物屏幕显示、测量精度和烧录结果仍需上板验证。
